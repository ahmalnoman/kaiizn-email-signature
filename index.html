Signature HTML

Install your signature

Add your signature in Gmail

  1. Back on this page, click Copy signature.
  2. Open Gmail → Settings → See all settings → General.
  3. Scroll to Signature → click Create new → name it e.g. Kaiizn.
  4. Click into the signature editor and paste (⌘V / Ctrl+V).
  5. Under Signature defaults, pick it for new mails and replies.
  6. Scroll down and click Save Changes.
Logo not showing? Send yourself a test email. Gmail caches the image on first load. If it still doesn't render, make sure the repo is deployed (e.g. GitHub Pages) so kaiizn-icon.png is publicly reachable.

Add your signature in Apple Mail (macOS)

  1. Click Copy signature on this page.
  2. Open Mail → menu bar → Mail › Settings › Signatures.
  3. Select your Kaiizn account in the left column.
  4. Click + to create a new signature, name it Kaiizn.
  5. Uncheck "Always match my default message font" (important).
  6. Click into the right pane and paste (⌘V).
  7. Set it as the default under Choose Signature.
iOS? Send the signature to yourself from macOS, then on iPhone go to Settings › Mail › Signature, long-press the field, and paste.

Add your signature in Outlook on the web

  1. Click Copy signature on this page.
  2. Open Outlook → top-right Settings ⚙ → Mail → Compose and reply.
  3. Under Email signature, click + New signature.
  4. Paste into the editor (⌘V / Ctrl+V).
  5. Pick it as default for new messages and replies → Save.

Add your signature in Outlook desktop (Windows/Mac)

  1. On this page, click View HTML and copy the HTML.
  2. In Outlook, open File → Options → Mail → Signatures… (Windows) or Outlook → Settings → Signatures (Mac).
  3. Click New, name it Kaiizn.
  4. Paste into the editor. If images disappear, use Copy signature from this page instead (rich copy) and paste.
  5. Set as default for new mail and replies.
Outlook Desktop has quirks with HTML signatures. If formatting breaks, use Copy signature (not "Copy HTML"), paste, and save.

Other clients

  1. Superhuman / Spark / Hey: Click Copy signature, then paste into the client's signature settings editor.
  2. Thunderbird: Click View HTML, save to a .html file, and point Thunderbird at it via Account Settings → Signature file.
  3. Anything else: If the editor accepts rich text, use Copy signature. If it only takes raw HTML, use View HTML → Copy HTML.
